Feedback Analysis — "Fallback Analyser"

A feedback-analysis project that aggregates user feedback and runs a multi-step analysis pipeline ("Fallback Analyser") to extract sentiment, key topics and fallback recommendations when confidence is low. Main points:

  • Preprocessing: cleaning, tokenization and basic normalization
  • Primary model: sentiment & topic extraction (e.g., simple classifier + keyword matching)
  • Fallback analyser: when primary model confidence is low, run an alternative lightweight heuristic pipeline to still provide useful insights
  • Output: dashboard with sentiment breakdown, top keywords, and suggested actions
